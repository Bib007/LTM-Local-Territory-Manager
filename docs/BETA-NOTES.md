# LTM 1.12.2-beta.75 · Privat server på valgt adresse

Startguiden kan nu genfinde en server på den private netværksadresse, som er valgt ved opsætningen. Det gør, at en server, der allerede kører, kan genkendes korrekt.

Hent den samlede programpakke til Mac, Windows og Linux, eller opdater HA-betaen som normalt. [Læs startguiden](https://github.com/Bib007/LTM-Local-Territory-Manager/blob/v1.12.2-beta.75/docs/SELF-HOSTING.md). Python skal stadig installeres separat; W74 er fortsat åbent.

OCR-arbejdet er fortsat på pause. Stabil forbliver 1.12.1.
