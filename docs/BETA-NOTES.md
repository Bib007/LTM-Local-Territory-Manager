# LTM 1.14.0-beta.5

- Ved tilføjelse af historik for et kort er »Kortet blev gennemgået« valgt på forhånd. Valget kan slås fra. En registrering uden indleveringsdato gemmes som aktiv udlevering uden gennemgang.

## English

- When adding a historical assignment, the completion checkbox is selected by default and can be cleared. An entry without a return date remains an active assignment without a completion.
