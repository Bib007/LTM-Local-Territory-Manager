# LTM 1.12.2-beta.74 · Egen computer eller server

Hent **LTM-v1.12.2-beta.74.zip**, pak den helt ud, og åbn **Start-LTM** for dit system i mappen **Distrikt-lokal**. Den nye startguide giver valget mellem lokal brug og en privat server til hjemmenetværk og egen VPN. [Læs vejledningen](https://github.com/Bib007/LTM-Local-Territory-Manager/blob/v1.12.2-beta.74/docs/SELF-HOSTING.md).

Serveren har eget login og datamappe. Den åbner ingen browser og stoppes med **Ctrl+C** i sit vindue. Betaens nye startguide bruger separate data fra stabil og HA. Python skal stadig være installeret; et separat appvindue og automatisk serverstart kommer senere. W74 er fortsat åbent.

HA-betaen opdateres som sædvanligt. OCR-arbejdet er fortsat på pause. Stabil forbliver 1.12.1.
