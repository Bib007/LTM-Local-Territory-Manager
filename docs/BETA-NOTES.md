# LTM 1.14.0-beta.1

- **Daglig brug:** Tydeligere valg mellem udlevering og aflevering. Vælg visning pr. forkynder eller i kortrækkefølge. Udlever op til fem ledige kort i én handling med samme dato og modtager, og få hurtigvalg til hyppige modtagere.
- **Kort og forside:** Kortfiltre viser antal og aktive valg. Ekstra kortværktøjer er samlet, og Kortoversigt kan zoome tilbage til hele distriktet. Forsiden har færre forklaringer og intet søgefelt.
- **Rapporter og indstillinger:** Samlet indstillingsnavigation med ændringshistorik under Brugsstatistik. Tre rapportfaner og mulighed for rapport uden grafisk kort ved fejl i kortvisningen.
- **Gemning og påmindelser:** Synlig gemmestatus i dialogen, hurtigere opslag ved udlevering og initialer på beskeder om gamle udleveringer for navngivne profiler.

## English

- **Daily work:** Clear issue and return actions, with return ordering by publisher or card. Issue up to five available cards in one transaction with the same date and recipient, and use shortcuts for frequently selected recipients.
- **Cards and home:** Card filters show counts and active selections. Additional card tools are grouped, and the overview map can zoom out to the entire district. The home page has less explanatory text and no search box.
- **Reports and settings:** A unified settings selector with change history in usage statistics. Three report tabs and an option to continue without a map if it fails to render.
- **Saves and reminders:** Visible dialog save status, faster issue lookup, and initials in overdue assignment reminders for named accounts.
