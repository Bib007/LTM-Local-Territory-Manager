# LTM 1.12.0-beta.36

Ét ønskepunkt: W53. Alle ændringer fra beta.30–35 er med.

- Opgaver kan gentages på en valgt ugedag. Forfaldne opgaver vises på forsiden og kan markeres udført der. Kommende forekomster kan ikke afsluttes for tidligt.
- Opgavetekst, kortreference og afslutningshistorik bevares. Næste gang bliver den valgte ugedag efter udførelsesdagen. Missede uger opretter ikke kopier eller opdigtede gennemførelser. Samme forekomst kan ikke afsluttes to gange.
- Historik/dato gemmes og fortrydes samlet; de bevares ved redigering, genstart og gendannelse. Ingen gentagelse stopper kommende forekomster uden at slette historikken. Ingen automatisk kortflytning, upload eller ekstern besked. Dansk/engelsk bevarer formularens tekst og valgte ugedag.

Tag fortsat en privat backup før opdatering. Ejerens faktiske API-hentning skal stadig prøves med rettelsen fra beta.30; grøn forbindelse alene er ikke nok. W61's eksterne GitHub-cache/PR-oprydning og udgivelsesmetadata er stadig åbne. W06 og den afhængige nøglebackup W56 er ikke færdigmeldt. Main er stabil 1.11.1.
