# LTM 1.12.0-beta.43

To ønskepunkter: W51 og W44.

- Rapporter samler tjenesteår og seneste 12 måneder i én oversigt med tydeligt adskilte perioder, nøgletal og grafer.
- Samlet print/PDF begynder med den fælles oversigt. Hvert periodekort beholder sin egen side med titel og datoer. Distriktets oplysninger og original S-13 følger fortsat efter kortene.
- Kortfanerne vælger det periodekort, der vises under den fælles digitale oversigt. Korthistorik og KTM-besøg bevares.
- Forsidens datoer forklarer nu perioden for gennemgange og anslåede besøg. Kort og opgaver viser aktuel status.

Prøv: Sammenlign de to perioders tal i Rapporter, vælg begge kortfaner og et tidligere tjenesteår. Åbn Print samlet rapport/PDF: begge perioders nøgletal skal være på første side, efterfulgt af hvert sit periodekort. Kontrollér også datoforklaringen på forsiden og dansk/engelsk. Gemte data, originale formularer og adressehentning ændres ikke. Main er stabil 1.11.1.
