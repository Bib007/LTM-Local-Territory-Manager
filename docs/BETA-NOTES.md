# LTM 1.15.0-beta.6

- Start Territory Helper-importen på opsætningsguidens første trin, godkend alle kort, og fortsæt guiden bagefter. Kontrollér importadvarsler under Opfølgninger.
- Saml importerede lokationer i vejlisten med de enkelte adresser bevaret. Første import opretter ingen genprintopgaver.
- Foreslå en redigerbar ydergrænse ud fra distriktskortene, hent DAR-adresser inden for grænsen, og find vejlinjer i kortnotater med hentede DAR-data.
- Godkend kort med ugyldige rækker, ret de oprindelige værdier i Opfølgninger, og fortsæt guiden under en delvis import. Foreslå DAR-adresser fra importerede koordinater og se, om en distriktsgrænse er gemt.
- Se hvilken CSV-række eller KML-grænse der kræver kontrol, og hvad LTM fandt i eksporten. Match KML efter kort-id, kortnavn og distriktstype i mappen eller en entydig eksisterende grænse.
- Vælg automatisk adresser inden for alle gemte kortgrænser med én handling. Bevar eksisterende adressevalg, og spring nye adresser i flere kortgrænser over. Ignorér alle kendte kortoverlap samlet under Opfølgninger.

## English

- Start the Territory Helper import from the first step of setup, approve all territories, and continue the guide. Review import warnings under Follow-ups.
- Group imported locations in the road list and keep individual addresses. The first import creates no reprint tasks.
- Suggest an editable outer boundary from territory cards, download DAR addresses within it, and find road lines in territory notes using downloaded DAR data.
- Approve cards with invalid rows, correct the original values in Follow-ups, and resume setup during a partial import. Suggest DAR addresses from imported coordinates and see whether a territory boundary is saved.
- See which CSV row or KML boundary needs review and what LTM found in the export. Match KML using territory ID, territory name and folder type, or one matching known boundary.
- Automatically select addresses within all saved territory boundaries in one action. Preserve existing address selections and skip new addresses within multiple boundaries. Dismiss all known boundary overlaps together under Follow-ups.
