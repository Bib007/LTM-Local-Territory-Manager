# LTM 1.12.19-beta.1 · Samme funktioner som Stable 1.12.19

Beta er ført ajour med alle rettelser fra Stable 1.12.19: hurtigere og sikre gemninger, samlet printgodkendelse, to-siders Drive-PDF, valgfri husnumre, korrekt læsearkiv, lokal krypteret forbindelsesbackup og historik med bruger.

Dette er fælles udgangspunkt. Nye funktioner og rettelser skal fremover afprøves på Beta, før de eventuelt flyttes til Stable.

- Home Assistant Beta: port 8788, eget login og egen datamappe. Opdatér Distrikt Beta gennem appbutikken.
- Mac og Windows: separate LTM Beta-installationsfiler med indbygget Python. Beta bruger egne program-/datamapper; Stable bevares.
- En almindelig Beta-opdatering bevarer tidligere Beta-prøvedata. Ingen data kopieres automatisk fra Stable.
- Brug opdigtede kort og en særskilt prøveforbindelse til Drive. Ingen ny funktion i denne synkroniseringsudgivelse kræver ændring af dine Stable-data.

Se [Stable-noterne](RELEASE-NOTES.md) for de samlede rettelser og [betavejledningen](BETA.md) for installation.
