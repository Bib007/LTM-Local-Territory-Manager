# Manual split suggestions — development preview

Open **Settings → Congregation and carry folder → Split suggestions**, or the optional item in the setup checklist. Choose an approximate visit target and whether to show only cards in the box. The target and filter are preferences in this browser; no account or territory data is stored in browser preferences.

The planner uses the loaded overview. Unknown, invalid or missing visit totals are excluded. Visit counts remain estimates, not records of actual house-to-house visits. The box filter excludes both issued cards and cards in the carry folder. With that filter off, an issued card can be reviewed but cannot open a split proposal. Receiving cards are always at home.

Address suggestions require exact, unique geographic membership whose known counts match the card's visit total. Whole address units stay together. Missing membership, retired units, duplicate membership and inconsistent totals prevent an address proposal. No geographic boundary or visit total is guessed.

A possible receiving card must have spare capacity and match the source area, type, street name and postcode. This identifies a numerical alternative, not verified geographic continuity. Alternatives are independent and must not be treated as a combined plan. Up to 100 oversized cards and three receiving alternatives per source are shown.

**Review split into a new card** opens the existing manual split form with the proposed address boxes selected. Enter a new number, review the server preview and explicitly confirm before a card can change. The existing server rules still reject active loans, changed data, ambiguous do-not-call membership and invalid splits. History stays on the original card; the new card has no invented completion and needs review and reprinting.

W116 remains open. Applying moves to an existing card and choosing a recent-completion policy or an interim temporary card are later parts of that wish. The current planner does not apply those moves, change completion dates or resume automatic territory division. Stable 1.12.3 does not include this development preview.
