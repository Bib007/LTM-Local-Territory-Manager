# Sprog og dækning

Dansk er standardsprog. Engelsk ændrer fast markeret betjening; brugerens navne, noter, søgninger og opbevarede værdier bevares. Originale formularer og print er danske.

| Område | Status på develop |
| --- | --- |
| Velkomst, navigation og forside | Dansk/engelsk klargjort |
| Kortregister, udlevering, aflevering og historik | Dansk/engelsk klargjort |
| Forkyndere, opgaver, noter og kortets IB | Dansk/engelsk klargjort |
| Indstillinger, backup og rapportskærme | Dansk/engelsk klargjort |
| Kortoversigt, adresselister og kortkontrol | Dansk/engelsk klargjort og prøvet |
| Geografisk editor, grænser og import | Dansk/engelsk klargjort og prøvet |
| Avanceret opsætning og lokal IB-import | Dansk/engelsk klargjort og prøvet |
| Google/QR | Dansk/engelsk klargjort og prøvet med fiktive svar |
| Fælles fejl og usikker gemning | Fælles fejl, kernemodulernes domænefejl og særskilte skriveforløb er klargjort og prøvet; tekniske kildediagnostikker bevares |
| Login | Dansk/engelsk klargjort og prøvet; adgangskontrol uændret |
| Dialoglabels, tastatur og fokus | Klargjort og prøvet med native Chromium-dialoger |
| Printbetjening | Næste opgave; originale formularer bevares |

[Køreplan](../KOREPLAN.md). Klargjort udviklingskode er ikke en stabil udgivelse.

Førstegangsopsætningen, den personlige plan, rundturen og Excel-/CSV-importens betjening kan vælges på dansk eller engelsk. XLSX-skabelonens kolonneoverskrifter er danske på begge sprog, så filformatet er entydigt. Importfejl fra serveren vises som dansk tekst; opsætning og lokal IB-import er nu klargjort. De danske bekræftelsesord OPRET KORT og IMPORTÉR IB er identiske på begge sprog.
