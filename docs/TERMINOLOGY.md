# Danish and English terminology

Use official public sources for congregation-specific terms; use ordinary product language for physical storage and software actions. Translations do not change existing record keys, user-entered names or geographical data.

| Dansk | English | Basis |
| --- | --- | --- |
| Distrikt | Territory | Organized, chapter 9, paragraphs 30–34 |
| Forkynder | Publisher | Organized, chapter 9 |
| Distriktstjener | Territory servant | Organized, chapter 9, paragraphs 32–33 |
| Tjenestetilsynsmand | Service overseer | Organized, chapter 9, paragraph 31 |
| Kredstilsynsmand / KTM | Circuit overseer / CO | Organized, chapter 5 |
| IB / Ikke besøges | Do-not-call / DNC | Descriptive English term; not claimed as a quotation from Organized |
| Gennemgang | Territory completion | UI wording for completion; the book uses cover/completed |
| Kort i mappen | Cards in the carry folder | Product wording, not an official designation |
| Kort i kassen | Cards in the storage box | Product wording |
| Besøg (antal adresser/enheder) | Visits (address/unit count) | Product count, not a record of individual ministry calls |

The public book says those obtaining a territory should endeavour to cover it within four months. The app uses this for follow-up; it should not be described as a software-imposed congregational rule.
