# LTM 1.12.16 · Two-page Drive cards and report cover

Share a single PDF with the digital map and its details on page one and a readable image of the printable front on page two. Long street lines wrap. In crowded areas, house-number labels follow the plotted dots and use leader lines. All saved addresses still use identical red dots. The do-not-call list stays on the physical card back.

To update a previously shared card, review both pages and approve the Drive upload in LTM. After approval, confirm the PDF opens from the card's current Drive link before using a printed QR code.

The internal report has a printable cover with the congregation name, plus rings for coverage and current card placement. Exact counts remain visible.
