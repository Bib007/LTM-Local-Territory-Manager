# LTM 1.12.25 · DAR-forslag, læsearkiv og sikkerhedskopier

- **DAR-forslag:** Den automatiske grænse holder andre kendte huse og lokalt gemte bygninger uden for kortet.
- **Nabokort:** Forslaget søger en omvej med mindst tre meters afstand til nabogrænser. En smal krydsning vises med en besked, når kortudsnittet kræver den for at forbinde de valgte huse.
- **Korteditor:** Brug **Foreslå grænse** til at beregne en ny grænse for adressevalget. Et forslag kontrolleres igen ved gemning. Hvis der ikke er en sikker grænse, kan den tegnes i hånden.

- **Læsearkiv:** Dan kortene samlet ud fra lokale kortdata, og få kortgrænser og adressepunkter i KML. Store arkiver pakkes på disk.
- **Sikkerhedskopi:** ZIP-navnet indeholder dato og klokkeslæt. Vælg Gem som i browsere med filvælger, eller brug browserens downloadindstillinger. Import understøtter ZIP-filer op til 512 MB.
- **Distrikter:** Åbn markerer kortet på listen, så markeringen passer, når du lukker kortet.
- **Samtidige rettelser:** Åbne redigeringer bevarer deres eget grundlag, mens brugerne arbejder på forskellige kort.

## English

- **DAR suggestions:** The automatic boundary keeps other known houses and locally saved buildings outside the territory.
- **Neighboring territories:** The suggestion looks for a detour at least three meters from shared boundaries. It shows a warning if the selected houses require a narrow crossing within the local map area.
- **Map editor:** Use **Suggest boundary** to recalculate the boundary for the selected addresses. The suggestion is checked again on save. If a safe suggestion is unavailable, draw the boundary by hand.
- **Readable archive:** Generate cards together from local map data and export boundaries and address points as KML. Large archives are assembled on disk.
- **Backup:** ZIP names include date and time. Use Save as in browsers with a file picker, or use browser download settings. Import supports ZIP files up to 512 MB.
- **Territories:** Open selects the card in the list so the selection is visible when you close it.
- **Concurrent edits:** Open editors retain their own starting point while users work on different cards.
