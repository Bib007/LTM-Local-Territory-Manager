# LTM 1.12.11 · IB, map and connection-backup preparation

Map markers preserve each saved visit location, including the focused map. Long do-not-call backs continue onto labelled extra print pages, and the new combined overview can be sorted by date or address while retaining month/year and year-only date wording.

Manual do-not-call lines can now offer a local address suggestion from the same card. The user reviews and confirms the address; no record is linked automatically, and the original record ID/date stay intact.

Connection credentials remain outside ordinary data/account backups. A connections administrator can create a browser-encrypted backup for Google Drive, Datafordeler and an optional Adressevælger token, then restore it explicitly and check each connection again.

This candidate also prepares independent Home Assistant, macOS app/server and Windows app/server release tracks from the same source/version. The first desktop artifacts are labelled Python ZIPs, not native DMG or EXE installers.
