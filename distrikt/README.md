# Distrikt Beta

Afprøv nye LTM-funktioner i små betaudgivelser ved siden af din stabile installation. Betaen bruger port 8788, egne data og eget login.

Læs fanen **Dokumentation** for installation, opdatering og den aktuelle testliste. Start med opdigtede prøveoplysninger og en særskilt Google-konto til Drive-prøver.
