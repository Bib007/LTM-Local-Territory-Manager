# Distrikt · Local Territory Manager

Lokal distriktsadministration med kort, forkyndere, udleveringer, gennemgange, IB, print og privat backup.

Appen har eget login og egen lokal adresse på port 8787. Den bruges på hjemmenetværket eller via VPN på egen router. Databaser og IB bliver på din HA-maskine. Google Drive-deling af godkendte kortbilleder er valgfrit.

Læs **Dokumentation** før første start og ved flytning fra en eksisterende lokal app. Appdata er udeladt af HA-backup; brug appens egen private backup.
